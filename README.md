# Portfolio

My personal site. Live at **[aryandhillon.vercel.app](https://aryandhillon.vercel.app)**.

Built with React 19, TypeScript, and Vite. No UI or animation libraries: the layout,
the CSS, and the interactive visuals are all hand-written.

Each project gets one live visual instead of a screenshot:

- **Vaila**, an AI scheduling app I founded and built, shown as a layered
  cross-section of the stack
- **Garmin**, embedded software under DO-178B, shown as a live TCAS traffic scope
- **Distributed key-value store**, an interactive request path beside its real
  benchmark ([source](https://github.com/aryan0dhi/distributed-kv-store))
- **Demand forecasting** for John Deere, shown as a probabilistic fan chart

All copy lives in `src/content/resume.ts`.
